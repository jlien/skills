# Content Brief for AI-Era Search

Framework for writing content that ranks on Google AND gets cited by AI Overviews (AEO).

## Core Principles

1. **One question per page** — what single question does this page answer?
2. **Each PAA question = one H2** — no intro fluff, each section stands alone
3. **AI reads sections independently** — each H2 must answer its question without the reader scrolling up

## Step 1: Research

Search `{keyword}` and fill in:

- **The Answer Block**: What one question does this page answer? Write 100-150 words as a direct answer. Find the PAA (People Also Ask) box on Google.
- **The Structure**: Each PAA question becomes one H2 section. Search `{keyword}`, find PAA questions, pick the strongest ones.
- **The Edge**: What do the top 5 results do? Your page needs original data, a specific ICP, or a named framework that others lack.

## Step 2: Draft the Brief Output

Hand this structure to the writer (or Claude):

| Field | Value |
|---|---|
| keyword | {your keyword} |
| core question | {the one Q} |
| AEO block | {150-word answer} |
| H2 map | {PAA questions as H2s} |
| reader | {specific person} |
| edge | {the one thing no one else has} |
| CTA | {one action} |
| EEAT signal | {quote / data point} |

## Step 3: Structure Rules

- **No intro** — the answer goes at top of page
- **No fluff** — each H2 stands alone
- **Edge** = original data, specific ICP, named framework, deeper subtopic, or "this page does X no one else has"
- If the brief isn't ready, don't force it — come back when you have the edge

## Step 4: Pre-Publish Checklist

ALL must be YES before publishing. Fix NOs first.

1. First 150 words answer the core question directly?
2. Every H2 maps to a PAA question?
3. Every section stands alone (makes sense without the rest)?
4. One cited data point per section?
5. Human gets something an AI summary doesn't?
